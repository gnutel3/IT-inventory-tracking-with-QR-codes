# IT Inventory QR

MVP веб-приложения для командного проекта по учету IT-инвентаря с QR-метками.

## Что уже есть

- панель с метриками;
- реестр техники с поиском и фильтрами;
- карточка устройства с QR-кодом, амортизацией, ремонтами и перемещениями;
- добавление и редактирование техники;
- пакетная печать QR-меток;
- мобильный режим инвентаризации с фиксацией расхождений;
- отчеты «где что» и «что списывать»;
- импорт CSV, подготовленный из Excel или вставленный из таблицы;
- сохранение состояния в `localStorage`.

## Как запустить

Из папки проекта:

```bash
python3 -m http.server 4173
```

Затем открыть:

```text
http://localhost:4173
```
